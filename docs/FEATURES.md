# 产品能力清单

## 用户端

- 手机号或账号登录、门店上下文切换、资料与安全设置
- 竞彩足球、篮球、北京单场、胜负过关及数字彩多玩法
- 传统足彩 14 场、任选 9 场、6 场半全场、4 场进球等玩法
- 订单、追号、合买、跟单、社区、即时比分、赛事直播与消息
- 钱包、充值、提现、优惠活动与完整交易记录

## 店主端

- 待处理订单、出票、拒单、退款和状态追踪
- 店主、店员及细粒度角色权限管理
- 门店资料、公告、投诉、客户与营销管理
- 资金流水、结算、对账、经营数据和设备管理
- 手机工作台与 PC 管理端共享真实业务数据

## 平台运营后台

- 商户、门店、账户、角色和权限治理
- 资金、订单、开奖、内容、活动与风控管理
- 操作审计、异常监控、任务状态与平台统计

## 说明

演示环境中的第三方支付、真实打款、硬件出票和签名安装包等能力可能受外部商户或设备条件限制。比分与赛事数据使用本系统自己的数据接口，不承诺与任何第三方页面逐项一致。
